## Installation - Developers
1. Make sure you have npm installed.
2. Run `npm install`.
3. Run `npm run compile`.
4. Go to your browser and navigate to the top right to "manage extensions".
5. Enable developer mode.
6. Load unpacked extension.
7. Select the project folder, where the manifest.json is located.
8. Enable the extension.
9. Use the extension on any valid webpage by clicking the extension icon.
